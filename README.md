# Swati Sharma — Portfolio

A minimalist, elegant, and highly responsive personal portfolio website crafted with modern web technologies.

## ✧ Overview

Welcome to my personal portfolio! This project serves as my digital resume, showcasing my skills, projects, and educational background. It's built around a calm, editorial blue-and-off-white palette, with a hand-drawn wordmark for personality and a single continuous scroll instead of a traditional multi-page layout.

## ✧ Key Features

- **Editorial Aesthetic** — a clean blue  and off-white design with a graph-paper texture on light sections and a radial glow on dark ones.
- **Buttery Smooth Scrolling** — integrated **Lenis** for a premium, native-feeling scroll experience.
- **Layered Motion System** — a GSAP-driven staggered "pop" reveal for cards/lists, a separate blur-to-clear reveal for section content, and Framer Motion for hover states and real 3D tilt-on-cursor project/skill cards.
- **High Performance** — fast load times powered by Vite, with no heavy icon-font dependency (icons are inline SVG).
- **Fully Responsive** — a clean layout across desktop, tablet, and mobile.

## ✧ Tech Stack

- **Framework:** React + TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS for custom animations
- **Animation:** GSAP, Framer Motion
- **Scrolling:** Lenis
- **Build Tool:** Vite

## ✧ Getting Started

To run this project locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/swati485/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npm run dev
   ```

4. Build for production:
   ```
   npm run build
   ```
